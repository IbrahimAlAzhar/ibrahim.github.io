# Ibrahim Al Azher — Academic Website

Source for my personal academic website: **https://ibrahimalazhar.github.io/ibrahim.github.io/**

Ph.D. researcher in Computer Science at Northern Illinois University working on **verifiable, evidence-grounded AI for science** — multi-agent LLM reasoning, verifiable reinforcement learning, scientific critique and synthesis, and trustworthy AI-assisted judgment.

Built with [al-folio](https://github.com/alshedivat/al-folio) (Jekyll) and deployed automatically to GitHub Pages by `.github/workflows/deploy.yml`.

## Where to edit things

| What                         | File                                  |
| ---------------------------- | ------------------------------------- |
| Name, URL, site settings     | `_config.yml`                         |
| Home page bio                | `_pages/about.md`                     |
| News items                   | `_news/YYYY-MM-DD-news.md` (one each) |
| Publications                 | `_bibliography/papers.bib`            |
| Research overview            | `_pages/research.md`                  |
| Projects                     | `_projects/*.md`                      |
| Talks, posters, service      | `_pages/talks.md`                     |
| CV page                      | `_data/cv.yml`                        |
| CV PDF                       | `assets/pdf/Ibrahim_Al_Azher_CV.pdf`  |
| Social links                 | `_data/socials.yml`                   |
| GitHub repos shown           | `_data/repositories.yml`              |
| Profile photo                | `assets/img/prof_pic.jpg`             |

To mark a paper as "selected" on the home page, add `selected = {true}` to its BibTeX entry.
