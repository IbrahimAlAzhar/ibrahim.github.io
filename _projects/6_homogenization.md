**Status:** preliminary experiments

AI can increase individual output while narrowing collective attention. This project measures that risk *inside* multi-agent reasoning.

- Specialist agents collectively recovered **79.0%** of reference limitations, but the synthesized report retained only **49.7%**.
- Critiques raised by several agents survived far more often than those found by a single agent (**85.5% vs. 57.5%**).
- Across eight LLM systems, generated critiques were **1.18–1.63× more similar across papers** than human references.

**Next:** an expert-adjudicated benchmark separating supported findings, valid-but-unrecorded findings, redundancy, and unsupported claims; aggregation that preserves **verified minority findings**; and human–AI studies testing whether this actually improves researchers' judgment.
